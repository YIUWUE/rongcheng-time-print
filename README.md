# 蓉城时光印

竖屏触控城市影像纪念应用。流程为选择风格、拍摄照片、生成与打印，省略独立报纸选择页。七套主题分别对应独立 HTML 报纸和图像提示词。

## 技术结构

- Python 与 PySide6：桌面触控界面、流程状态和后台任务。
- Qt Multimedia：摄像头预览、倒计时拍摄和拍后确认。
- 火山方舟 Seedream API：以本次拍摄人像为参考生成主题影像；不包含本地模型权重。
- HTML/CSS 与 Qt WebEngine：将 AI 图片嵌入对应报纸模板，生成单页 A4 PDF。
- Qt PDF：生成 300 DPI 预览与打印图；预览和打印共享同一份输出。
- PyInstaller：打包 Windows 可执行程序。

`ui.py` 负责界面与流程，`camera.py` 负责采集，`catalog.py` 定义风格与模板绑定，`services.py` 封装生成和打印任务，`rendering.py` 负责报纸排版及高清输出。

仓库仅包含源码、模板、效果示例与测试，不包含 API 密钥、现场用户照片、生成记录或打包程序。公开仓库不等于为全部素材授予开源许可；本仓库未指定整体开源许可证，第三方图标保留其随附许可证。

## 启动

```powershell
python -m pip install -r requirements.txt
python main.py --windowed
```

`run_windowed.bat` 用于电脑窗口体验，`run.bat` 用于设备全屏运行。默认在横向显示输出上将界面旋转为竖屏；原生竖屏不旋转。可使用 `RONGCHENG_ROTATED_KIOSK=0` 关闭旋转，或 `=1` 强制旋转。

## 服务配置

在 Windows 环境变量中设置 `HUOSHAN_API_KEY`。可通过 `HUOSHAN_SEEDREAM_MODEL` 指定已开通的图像模型。认证配置从进程环境变量与 Windows 用户/系统环境变量读取，不在文件中保存密钥。

## 模板和输出

`templates/` 包含七套已适配的单页 A4 HTML，`catalog.py` 定义风格与提示词的一一对应关系。报纸保留用户原始模板的标题、正文、栏目、页脚及静态图章，主照片替换为本次 AI 图片。通过 `time[data-live-field]` 明确标记的日期、星期和时间使用 AI 出图成功时的系统北京时间（UTC+8），不改正文历史年份、营业时间或期号。原来没有出图日期的熊猫、采耳模板在页脚补充时间。导出、预览、打印和失败后的排版重试使用同一份时间快照。模板自带、不参与打印的主题切换控件及脚本不进入最终报纸。

春熙路和水墨草堂模板的信息栏仅保留日期、星期和时间，移除天气、温度、光照、地点及“第几天”等预设元数据，不删除正文中的文学描写。两套故事时间轴的末格“盖下时光印”使用本次出图的真实时间，显示到分钟（HH:mm），不显示秒；前四格分别按春熙路 18/12/7/2 分钟、草堂 30/22/14/5 分钟倒推，搭配主题化故事文案，不代表用户真实行程。跨日节点补充月日。偏移量通过 `time[data-live-field="story-time"][data-minutes-before]` 配置。其余五套模板的原有天气文案未接入实时数据，也未在本次修改。

图像生成后自动嵌入所选 HTML，渲染成单页 PDF，并输出 2480×3508 的 300 DPI PNG。预览和打印使用同一份 PDF 结果。照片区域按各自版式等比裁切；不拉伸。

相机优先选择 1920×1080 / 30fps；硬件不支持时选择最接近格式。F8 可查看实际格式。预览与截取使用同一视频帧，不做水平镜像。可使用 `RONGCHENG_CAMERA_ROTATION=90` 等值校正镜头安装角度。

倒计时拍摄后停留在拍摄页，冻结照片并显示“重拍”和“使用照片生成”。重拍会丢弃未确认照片，保留所选风格并重新开启摄像头；只有点击“使用照片生成”后才调用 AI。确认界面不会被延迟到达的相机帧或倒计时覆盖，窗口缩放也不会再次裁切已拍照片。三步主流程不变。

首屏采用大图轮播与七张缩略图，支持箭头、左右滑动和键盘方向键。七张封面使用用户本次提供的效果示例，保留原图，不进行裁切或去除标记。它们仅用于界面展示，不会作为身份参考发送给 AI。

显示顺序为青城山仙侠风、双子塔赛博朋克风、亲亲抱抱大熊猫、来采耳吧、回锅肉大厨、春熙路时尚杂志、水墨淡彩写实。完成本次拍摄与 AI 创作后，生成图会自动替换到对应报纸中。

运行数据默认保存在 `runtime/`。该目录包含创作影像和打印输出，应按现场需要管理；交付源文件和程序时排除该目录。也可使用 `RONGCHENG_DATA_DIR` 指定其他可写目录。

## 打印

安装实体打印机驱动并设为默认打印机，使用 A4 纵向纸张。提交时立即禁用打印按钮，提交成功后不允许同一作品再次提交；结果未知时保持锁定，请先检查打印队列。纸边和颜色仍取决于实际驱动及纸张。

## 构建

```powershell
python -m pip install PyInstaller
python -m PyInstaller --clean --noconfirm build.spec
```

输出目录为 `dist/蓉城时光印/`。将整个目录一起发送；Qt WebEngine 的子进程和资源文件在 `_internal/` 内，不能只发送 EXE。
