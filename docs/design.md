# 蓉城时光印

产品使用三步竖屏流程：选择风格、拍摄照片、生成与打印。风格与报纸固定绑定，不再提供独立报纸选择页。

七个风格按用户要求排序：qingcheng、cyber、panda、ear_cleaning、chef、fashion、ink。每套都使用独立提示词和版式，切换主题时同步绑定对应模板，原有提示词不变。

主视觉只使用本次拍摄作为身份参考，通过火山方舟图像生成接口完成创作。模型 ID 与密钥分别读取 HUOSHAN_SEEDREAM_MODEL 和 HUOSHAN_API_KEY。密钥不写入文件，不复制既有运行记录。

模板保留用户上传原稿的标题、正文、栏目、页脚与静态图章，通过明确的照片占位符替换本次 AI 主图。AI 出图成功时记录系统北京时间（UTC+8），仅通过 `time[data-live-field]` 更新报头的日期、星期与时间；原来没有日期栏的熊猫、采耳模板在页脚补充时间。预览、PDF、打印及排版重试共享同一时间快照，不改历史年份、营业时间或期号。不打印的主题切换控件和脚本不进入报纸。Qt WebEngine 负责渲染，Qt PDF 校验单页并生成 300 DPI 打印图；屏幕预览与打印来自同一 PDF。原文回归测试逐套对照上传内容，排版修正不得删减或改写文字。

用户已授权调整春熙路与草堂的时间轴：末格“盖下时光印”记录本次真实出图时间，其余节点按主题故事倒推，统一显示到分钟（HH:mm），不显示秒，跨日补充月日。这些前置节点是创意叙事，不声称是用户真实游览轨迹。两套信息栏仅保留日期、星期、时间，移除天气、温度、光照、地点及“第几天”等元数据；正文中的诗句与文学描写不改。故事偏移量写在模板的 `data-minutes-before` 属性中，春熙路为 18/12/7/2/0 分钟，草堂为 30/22/14/5/0 分钟。

界面使用冷白背景、墨色文字、清晰的蓝色操作强调与单色线条图标。首屏为大图轮播与七张原图缩略图，图片等比完整展示，不裁掉人物或原图标记。封面仅用于效果展示，不参与用户身份参考。主图支持按钮、鼠标或触控合成的左右滑动、键盘方向键，切换使用短淡入淡出。

摄像头帧由同一图像管线预览和截取，优先选择 1920×1080、30fps；图像不应用水平镜像。设备旋转由外层显示视图承担。生成页使用环形 AI 动画、实际已等待时间与三项真实阶段状态；打印页使用大画面和独立加减份数按钮。

拍摄页内部包含实时取景、倒计时和照片确认三个状态，不新增主步骤。拍后停止相机并完整显示已截取照片，用户可以重拍或点击“使用照片生成”；确认前不读取服务密钥、不启动生图任务。重拍清空未确认影像并创建新会话，保留当前风格。相机帧、状态消息和旧倒计时回调不能覆盖确认画面；重复确认不能重复提交生成任务。

打印任务在发出前锁定，成功提交后保持禁用，只有明确失败或新会话时重置。生成与渲染期间禁止跳步；会话超时不打断未完成的后台任务。

验证范围覆盖七套模板原文与静态图章对照、单页 A4、图片与明确时间字段替换、北京时间跨日转换、实际出图时间记录、提示词对应、无旧学校品牌与旧人像资源、重复打印拦截、原生竖屏与旋转视图。模板原稿中的历史人物、诗句和地标介绍属于报纸正文，应予保留。付费生图、实机相机和纸张校准仍需现场验收。
